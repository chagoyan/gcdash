Setup

  1. Enable the Google Classroom API in Google Cloud Console.
  2. Create an OAuth 2.0 Client ID (Web application type).
  3. Add http://localhost:8080 as an authorized JavaScript origin.
  4. Paste your Client ID below and click Connect.
Your credentials stay in the browser — nothing is sent to any server.
