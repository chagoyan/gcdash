chsserver01.org → Google Drive Transfer

One-time tool: finds every Classroom link pointing at a given domain across your Active courses and copies the actual files into Google Drive, organized by course and week.
Files are matched only if they're currently linked from an assignment or material in Classroom — this does not touch anything else on the server. The same file linked from multiple courses/weeks is uploaded once and linked into every relevant Drive folder, so nothing is duplicated. If a file can't be fetched (e.g. the server doesn't allow cross-origin access), it's skipped and listed in a COULD-NOT-TRANSFER file dropped into the Drive folder so nothing fails silently.
